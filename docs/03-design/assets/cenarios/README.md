## Como referenciar nos seus prompts ou código

* **Caminho relativo a partir da raiz:** `assets/cenarios/<nome-do-arquivo>.jpeg`
* **Caminho no design:** `docs/03-design/assets/cenarios/<nome-do-arquivo>.jpeg`
* **Para usar no frontend web:** Podem ser movidas/copiadas para `web/public/cenarios/` quando forem utilizadas em tela.
