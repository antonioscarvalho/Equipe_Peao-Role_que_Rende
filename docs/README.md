## Como manter

1. Campos marcados com `_a definir_` ou `TODO` estão pendentes.
2. Toda mudança de decisão entra no [diário de bordo](05-processo/diario-de-bordo.md) com data e hora.
3. Todo uso novo de IA, biblioteca, API ou asset entra **na hora** em [07-conformidade](07-conformidade/), não no fim do Dia 3.
